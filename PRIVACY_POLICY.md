# Khmerlang Privacy Policy

Effective date: July 12, 2026

Khmerlang Keyboard is designed to process typing locally on your device whenever possible. Cloud spell check is optional and disabled by default.

## What we collect

- Keyboard input is processed on-device for local suggestions and corrections.
- If you enable cloud spell check, text before your cursor is sent to Khmerlang servers to return spelling suggestions.
- If you pick a cloud suggestion, we may send the original word and selected suggestion to improve ranking quality.

## What we do not collect

- We do not require account sign-in to use the keyboard.
- Cloud spell check is not active unless you explicitly consent and enable it in the app.
- If cloud spell check is disabled, typed text is not sent to Khmerlang servers.

## Permissions

- Full Access is required only for cloud spell-check network requests.
- Without Full Access, cloud spell check cannot run and the keyboard continues with local features.

## Data use and retention

- Cloud spell-check requests are used to generate spelling suggestions.
- Selection feedback may be used to improve suggestion ranking.
- We retain only the minimum operational data needed to run and improve the service.

## Security

- Network communication uses HTTPS.
- We apply reasonable safeguards to protect data in transit and at rest.

## Your choices

- You can disable cloud spell check at any time in the Khmerlang app.
- You can revoke keyboard Full Access in iOS Settings at any time.

## Contact

Questions can be sent to privacy@khmerlang.com.

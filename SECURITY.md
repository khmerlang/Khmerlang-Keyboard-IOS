# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Khmerlang Keyboard (for example,
an issue affecting user data, the cloud spell-check API, or the keyboard
extension's handling of Full Access), please report it privately rather
than opening a public issue.

Email **privacy@khmerlang.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, screenshots, or proof-of-concept code

We'll acknowledge your report as soon as possible and work with you on a
fix and disclosure timeline before any public discussion.

## Scope

This covers the iOS app and keyboard extension in this repository, and the
`ml/roman2khmer` model pipeline. It does not cover the Khmerlang backend
spell-check service itself, which is a separate system.
